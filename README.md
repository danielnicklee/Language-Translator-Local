Language Translator

------------------------------------------------------------------------------------
A locally run language translator designed for convenient and simple personal use.
It is a handy tool created to go beyond the limitations of standard online translators, allowing users who need to study various sentence structures and vocabulary, not just basic meaning transfer. 

#Currently supported languages include English, Japanese, and Korean. 

(This project is currently under continuous revision. The code and program for this personal translator were developed and modified using local LLMs.)
